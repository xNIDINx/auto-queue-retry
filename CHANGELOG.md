# История версий

## 1.3.1

- Уточнено назначение: поиск «Генерального сражения» через повторение коротких попыток в очереди случайных боёв при включённой соответствующей настройке игры.
- Автор обозначен как `nidin`; идентификатор пакета изменён на `nidin.auto_queue_retry`.
- Новое название в ангаре: «Поиск генерального сражения (nidin)».
- Однократный перенос всех пяти настроек со старого идентификатора без дублирования пункта меню.

## 1.3.0

- Лимит автоматических перезапусков: по умолчанию 20, диапазон 5–100 с шагом 5.
- После достижения лимита следующий поиск продолжается без тайм-аута отмены.
- Сохранение ранее выбранных времени ожидания, паузы и горячей клавиши при обновлении шаблона настроек.

## 1.2.0

- Настраиваемая горячая клавиша запуска и отмены через ModsSettingsAPI. По умолчанию F8.

## 1.1.1

- Настраиваемая пауза между попытками: 1–15 секунд с шагом 0,5 секунды. По умолчанию 2 секунды.

## 1.1.0

- Настройки в ангаре через ModsSettingsAPI.
- Настраиваемое время ожидания очереди: 5–60 секунд с шагом 1 секунда.
- Переключатель включения мода.

## 1.0.1

- Поправка таймера для выхода примерно на 15-й секунде видимого ожидания.
- Пауза перед повторным поиском увеличена до 2 секунд.

## 1.0.0

- Автоматический повтор поиска одиночного случайного боя.
- Запуск и отмена по F8.
- Остановка при найденном бое и ошибках очереди.
